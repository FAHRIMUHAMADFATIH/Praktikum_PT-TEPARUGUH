## Deskripsi Sistem

Sistem Informasi Inventory PT Teparuguh merupakan aplikasi berbasis web yang digunakan untuk mengelola persediaan dan distribusi produk sepatu secara terintegrasi.

## Fitur

- Login dan Register
- Dashboard Admin
- Dashboard Pengguna
- Manajemen Produk
- Manajemen Stok
- Manajemen Vendor
- Distribusi Barang

## Teknologi

- PHP
- MySQL
- AdminLTE 4
